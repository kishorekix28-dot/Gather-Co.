AGV Forklift

Autonomous Guided Vehicle for Industrial Material Handling

Overview

This project is an Autonomous Guided Vehicle capable of transporting materials inside industries.

Problem Statement

Manual transportation consumes more time and requires manpower. This project aims to automate material movement inside industries.

Objectives

  • Build an AGV
  • Avoid obstacles
  • Carry loads
  • Reduce manual work

Hardware Used

  • Arduino UNO
  • Motor Driver
  • Ultrasonic Sensor
  • DC Motors
